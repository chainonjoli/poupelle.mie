# 初期設定ガイド(3分で終わります)

Salon Replyは設定なしでも使えますが、
一度設定すると **「あなたのサロンの言葉」** で返信が出るようになります。

## やり方

チャットにこう送るだけです。

> 初期設定

すると、次のような質問が **一度にまとめて** 届きます(何往復もしません)。

1. サロン名
2. 業種(エステ / ネイル / まつ毛 / リラクゼーション / その他)
3. 主な客層
4. ふだんの文章の雰囲気(丁寧め / フレンドリー / 中間)
5. 絵文字(使わない / 1通に1個くらい / 多め)
6. 文章の長さ
7. 営業感(売り込み一切なし / 自然な範囲ならOK)
8. キャンセルポリシー
9. 遅刻のときのルール
10. 予約方法
11. 営業時間と定休日
12. 初回のお客様に必ず伝えたいこと
13. 接客で大切にしていること

**答えられるところだけでOK**。飛ばした項目は、感じのいい標準設定で動きます。

## 設定の保存について

- **claude.aiで使っている場合**: 設定をまとめた「わたしのサロン設定」ブロックが
  出力されるので、コピーして保存してください。
  - おすすめ: **プロジェクト機能** を使い、プロジェクトの指示欄にこのブロックを
    貼っておくと、毎回自動で反映されます。
  - プロジェクトを使わない場合は、新しいチャットの最初に貼り付けてください。
- **Claude Code / Cowork(ファイル操作ができる環境)の場合**: `my-salon.md` という
  ファイルとして保存され、以後は自動で読み込まれます。

## 特に設定してほしい2つ

1. **キャンセルポリシー** — 設定が無いと、Salon Replyは安全のため
   キャンセル料に一切言及しません。「当日50%」など決まりがあるなら必ず登録を。
2. **文章の雰囲気と絵文字** — ここが合うと「自分が書いたみたい」になります。
   ふだんお客様に送っている実際のLINEを1〜2通貼って
   「こんな感じで」と伝えるのが一番早いです。

## あとから変えたいとき

いつでもチャットで言うだけです。

> 絵文字もう少し多めにして。この設定で保存して

> キャンセルポリシーを「当日100%」に変更して

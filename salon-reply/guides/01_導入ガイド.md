# 導入ガイド(インストール方法)

Salon Replyは「Agent Skill」という、AIへの指示書をまとめたフォルダです。
中身はすべて普通のテキストファイル(Markdown)なので、開いて読んでも壊れません。

## 対応環境について(正直にお伝えします)

- **動作確認済み**: Claude Code(Anthropic社)
- **未確認**: claude.ai(ブラウザ/アプリのSkills機能)・Claude Desktop
  — 同じ「Agent Skills」仕様のため使える見込みですが、実機での動作確認は行っていません
- Skills機能はClaudeの有料プラン向けの機能です。最新のプラン条件はAnthropic社の案内をご確認ください

---

## 方法1: claude.ai(ブラウザ / スマホアプリ)で使う ※未確認環境(公式仕様に基づく手順)

1. 商品に含まれる `salon-reply` フォルダを **ZIP圧縮** します
   - Windows: フォルダを右クリック →「圧縮先」→「ZIPファイル」
   - Mac: フォルダを右クリック →「"salon-reply"を圧縮」
2. [claude.ai](https://claude.ai) にログイン
3. 左下の自分のアイコン → **Settings(設定)** → **Capabilities** → **Skills** を開く
4. **Upload skill** から、作ったZIPをアップロード
5. 新しいチャットを開いて、お客様のメッセージを貼り付けて「返信考えて」と送る

これで完了です。

> 画面の名称や場所はClaudeのアップデートで変わることがあります。
> 見つからないときは、Claudeのチャットに「スキルをアップロードしたい」と
> 聞くと現在の手順を案内してくれます。

## 方法2: Claude Code / Claude Desktopで使う ※Claude Codeは動作確認済み(Desktopは未確認)

パソコンにClaude Code(またはClaude Desktopアプリ)を入れている方向けです。

1. `salon-reply` フォルダを、ホームフォルダの `.claude/skills/` の中にコピーします
   - 例(Mac/Linux): `~/.claude/skills/salon-reply/`
   - 例(Windows): `C:\Users\あなたの名前\.claude\skills\salon-reply\`
2. Claudeを起動し、お客様のメッセージを貼るだけ。自動でSalon Replyが働きます

## 方法3: Skills機能が使えない環境の場合(応急処置)

Skills機能が使えないプラン・環境でも、`salon-reply/SKILL.md` の中身(と、必要な場面の
references ファイル)をチャットの最初に貼り付ければ、同じ指示で動かせます。
プロジェクト機能があるAIなら、プロジェクトの指示欄に貼っておく方法もあります。
※この方法はSkills機能ほど自動的ではありませんが、内容は同じです。

## 動作確認

導入できたか確かめるには、チャットにこう送ってください。

> 「明日空いてますか?」ってお客様から来ました。返信考えて

【状況メモ】と【おすすめ返信】の形で返ってくれば成功です。

## 他のAI(ChatGPTなど)について

Salon Replyの中身はテキストなので、他のAIに貼り付けて使うこと自体は可能ですが、
**動作を確認できているのはClaudeのみ** です。他環境での品質は保証できません。

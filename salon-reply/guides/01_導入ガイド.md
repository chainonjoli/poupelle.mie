# 導入ガイド(インストール方法)

Salon Replyは「Agent Skill」という、AIへの指示書をまとめたフォルダです。
中身はすべて普通のテキストファイル(Markdown)なので、開いて読んでも壊れません。

## 対応環境(正直にお伝えします)

- **動作確認済み**: Claude Code
  (Salon Replyを実際に読み込ませ、22ケースの返信生成テストを実施済み)
- **公式仕様上対応(Salon Reply自体の実機テストは未実施)**:
  claude.ai(Web/アプリのカスタムスキル)・Claude Cowork(デスクトップアプリ)
  — Anthropic公式の仕様・ヘルプで、ZIPアップロードによるカスタムスキル追加が案内されています
- **未確認**: 上記以外の環境(他社のAIなど)

対応プラン: カスタムスキルが使えるプランについては公式情報の記載に幅があるため、
**最新の対応プラン・必要な設定はAnthropic公式ヘルプ(support.claude.com)をご確認ください。**
なお、利用にはClaude側で「コード実行とファイル作成」機能を有効にする必要がある場合があります。

---

## 方法1: claude.ai(ブラウザ / アプリ)で使う ※公式仕様に基づく手順

**同梱の「Claudeにアップロードするファイル/salon-reply.zip」をそのまま使います。
このZIPは解凍しないでください。**

1. [claude.ai](https://claude.ai) にログイン
2. サイドバーの **Customize(カスタマイズ)** → **Skills(スキル)** を開く
3. **「+」→ スキルをアップロード** から、`salon-reply.zip` を選ぶ
4. 一覧に「salon-reply」が表示されたらONにする
5. 新しいチャットで、お客様のメッセージを貼り付けて「返信考えて」と送る

> メニューの名称・場所はClaudeのアップデートで変わることがあります
> (「Settings > Features」等の表記だった時期もあります)。見つからないときは、
> Claudeのチャットに「カスタムスキルをアップロードしたい」と聞くと現在の手順を案内してくれます。

## 方法2: Claude Cowork(デスクトップアプリ)で使う ※公式仕様に基づく手順

1. 左サイドバーの **Customize** をクリック
2. **Skills** タブを開き、アップロードから `salon-reply.zip` を選ぶ(解凍不要)
3. あとはチャットにお客様のメッセージを貼るだけ

※Coworkでは `~/.claude/skills/` へのフォルダコピーではなく、
アプリ内のアップロードが公式の導入方法です。

## 方法3: Claude Code で使う ※動作確認済み

パソコンでClaude Code(ターミナル版)を使っている方向けです。

1. 商品内の `skill/salon-reply` フォルダを、次の場所にコピーします
   - 自分専用: `~/.claude/skills/salon-reply/`
   - 特定のプロジェクト用: プロジェクト内の `.claude/skills/salon-reply/`
2. Claude Codeを起動し、お客様のメッセージを貼るだけ。自動でSalon Replyが働きます

## 方法4: Skills機能が使えない環境の場合(応急処置)

`skill/salon-reply/SKILL.md` の中身(と、必要な場面のreferencesファイル)を
チャットの最初に貼り付ければ、同じ指示で動かせます。
プロジェクト機能があるAIなら、プロジェクトの指示欄に貼っておく方法もあります。
※この方法はSkills機能ほど自動的ではありませんが、内容は同じです。

## 動作確認

導入できたか確かめるには、チャットにこう送ってください。

> 「明日空いてますか?」ってお客様から来ました。返信考えて

【状況メモ】と【おすすめ返信】の形で返ってくれば成功です。

## 他のAI(ChatGPTなど)について

Salon Replyの中身はテキストなので、他のAIに貼り付けて使うこと自体は可能ですが、
動作確認済みはClaude Codeのみ、公式仕様上の対応はClaude製品のみです。
他社AIでの品質は保証できません。

# Salon Reply v1.0.1 をご購入いただきありがとうございます

このファイルだけ読めば、使い始めるまでの全部が分かります。

## これは何?

**Salon Reply** は、個人サロンオーナーのための「接客返信AIスタッフ」です。
お客様から届いたLINEやDMをAI(Claude)に貼り付けるだけで、
「前日キャンセル? 当日? 常連さん? ポリシーはある?」といった **経営判断まで考えた返信文** が返ってきます。
中身はすべて普通のテキストファイルなので、開いても壊れません。

## どの環境で使える?

- **動作確認済み**: Claude Code
- **公式仕様上対応(Salon Reply自体の実機テストは未実施)**: claude.ai・Claude Cowork(デスクトップアプリ)
  — Anthropic公式仕様でカスタムスキルのZIPアップロードが案内されています
- **未確認**: その他の環境(他社AIなど)
- 対応プランは変わることがあるため、最新はAnthropic公式ヘルプをご確認ください
  (Claudeの利用料は本商品に含まれません)

## 何をすればいい?(3ステップ)

1. **入れる**(5分):
   - claude.ai / Cowork の方: **「Claudeにアップロードするファイル/salon-reply.zip」を
     解凍せずそのまま** Customize → Skills からアップロード
   - Claude Code の方: `skill/salon-reply` フォルダを `~/.claude/skills/` にコピー
   - 詳しくは `guides/01_導入ガイド.md`
2. **初期設定**(3分): Claudeのチャットで **「初期設定」** と送り、
   サロン名・文体・キャンセルポリシーなどを答えます(答えられるところだけでOK。
   設定しなくても「丁寧・親しみやすい・押し売りしない」標準設定で動きます)
   → 詳しくは `guides/02_初期設定ガイド.md`
3. **使う**: お客様のメッセージをコピーして、チャットに貼って送るだけ

## 使い始めのイメージ

> あなた:「すみません、明日の予約キャンセルでお願いします」← お客様のLINEを貼るだけ
>
> Salon Reply:
> 【状況メモ】前日キャンセルなので、快く受けつつまた来やすい空気を残す方針です。
> 【おすすめ返信】ご連絡ありがとうございます。大丈夫ですよ😊 …(そのままコピペ可)

しっくりこなければ「もう少しやわらかく」「短く」と言うだけで調整されます。
詳しくは `guides/03_使い方ガイド.md` へ。

## 大事なこと(必ずお読みください)

- 返信案は **送る前に必ず一読** してください。空き時間などは【穴埋め】になっています
- Salon Replyは医師ではありません。診断や薬の指示はせず、安全側の案内をします
- 「⚠ オーナー判断が必要」と出たケース(返金・補償・健康被害・法的な話)は、
  AI任せにせず必ずご自身で判断してください

それでは、返信に悩まない毎日をどうぞ。

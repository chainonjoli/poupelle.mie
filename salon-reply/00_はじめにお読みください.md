# Salon Reply をご購入いただきありがとうございます

このフォルダに入っているものと、最初にやることのご案内です。

## 最初にやること(2ステップ)

1. **`guides/01_導入ガイド.md`** を開いて、Salon ReplyをClaudeに入れる(5分)
2. Claudeのチャットで **「初期設定」** と送って、サロン情報を登録する(3分)

これだけで、お客様のメッセージを貼れば返信案が出るようになります。

## フォルダの中身

```
salon-reply/
├── 00_はじめにお読みください.md ← いまここ
│
├── skill/
│   └── salon-reply/          ← Salon Reply本体(これをClaudeに入れます)
│       ├── SKILL.md          … AIへの指示書(本体)
│       ├── README.md         … 取扱説明書
│       ├── references/       … シーン別の対応ルール6種
│       ├── examples/         … 実例集(Before/After・困ったケース)
│       └── tests/            … 品質テストの記録
│
├── guides/
│   ├── 01_導入ガイド.md       ← インストール方法
│   ├── 02_初期設定ガイド.md
│   ├── 03_使い方ガイド.md
│   └── 04_FAQ.md
│
└── sales/                    … (販売者用資料。購入者の方は読まなくてOKです)
```

## 60秒でわかる使い方

お客様のLINEをコピー → Claudeに貼り付け → 送信。

> 「すみません、明日の予約キャンセルでお願いします」

と貼るだけで、状況(前日? 当日? 常連さん?)を判断した返信案が返ってきます。
そのままコピペして送るか、「もう少しやわらかく」と言って調整してください。

## 大事なこと

- 返信案は送る前に必ず一読してください(空き時間などは【穴埋め】になっています)
- 「⚠ オーナー判断が必要」と出たケース(返金・健康被害など)は、AI任せにしないでください

困ったら `guides/04_FAQ.md` へ。それでは、返信に悩まない毎日をどうぞ。

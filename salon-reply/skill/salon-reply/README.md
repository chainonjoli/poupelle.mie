# Salon Reply — ひとりサロンの接客返信AIスタッフ

LINEを見て「なんて返そう…」と悩む時間をなくすための、個人サロン専用AIスタッフです。

## Salon Replyとは

お客様から届いたLINEやDMを貼り付けるだけで、
**「この状況なら、サロン経営者としてどう返すのが適切か」まで考えた返信文** を作るAIスキルです。

普通のAIとの違いは「判断」です。
同じ「今日キャンセルしたいです」でも、前日か当日か、初回のお客様か常連さんか、
お子さんの発熱か理由なしか、キャンセルポリシーがあるか無いかで、正しい返信は変わります。
Salon Replyはその背景を考えてから文章を作ります。

## できること

- 予約問い合わせ・日程変更への返信
- キャンセル対応(前日/当日/直前/無断)— ポリシーの伝え方まで判断
- 遅刻連絡への対応
- 初回来店前のご案内
- 施術後の「赤くなった」「ヒリヒリする」などの相談(安全最優先・診断はしません)
- クレーム・不満への対応(謝りすぎない、でも誠実に)
- 嬉しい口コミ・お礼への返信
- 次回予約への自然なご案内(押し売りしません)

## 導入方法

Salon Replyは「Agent Skill」という形式のファイル一式です。
**中身はぜんぶ普通のテキストファイル** なので、壊す心配はありません。

### Claude(claude.ai)で使う場合

1. claude.ai にログイン → 設定(Settings)→「Capabilities」→「Skills」を開く
2. この `salon-reply` フォルダをZIPにしてアップロード
3. チャットでお客様のメッセージを貼って「返信考えて」と送るだけ

### Claude Code / Claude Desktop(Cowork)で使う場合

1. `salon-reply` フォルダを `~/.claude/skills/` の中にコピー
2. チャットでお客様のメッセージを貼るだけ(自動でこのスキルが働きます)

※画面の名称はアップデートで変わることがあります。詳しくは同梱の「導入ガイド」をどうぞ。

## 最初の設定(3分・あとからでもOK)

チャットで **「初期設定」** と送ってください。
サロン名・文章の雰囲気・キャンセルポリシーなどを一度に質問されるので、
答えられるところだけ答えれば完了です。

設定しなくても「丁寧・親しみやすい・押し売りしない個人サロン」として今日から使えます。

## 基本的な使い方

お客様のメッセージをコピーして、貼り付けて、送る。それだけです。

```
あなた:
「明日の予約なんですが、子どもが熱を出してしまってキャンセルしたいです」
↑これ返信考えて

Salon Reply:
【状況メモ】当日キャンセル×お子さんの発熱です。ポリシーがあるため
「請求する案」と「今回は免除する案」の2案を出します。

【おすすめ返信】…(そのままコピペできる文章)
```

返ってきた文章は、
- そのままコピペして送る
- 「もう少しやわらかく」「短くして」と言って調整する
のどちらでもOKです。

`examples/before-after.md` に、普通のAIとの比較10ケースが入っています。
`examples/difficult-cases.md` には、無断キャンセル・クレーム・返金要求など

## 大事な注意(必ずお読みください)

- Salon Replyは **医師ではありません**。お客様の症状に診断や治療の指示はせず、
  安全側の案内(様子見・サロンへ連絡・医療機関へ相談)をします。
- 返金・補償・重大なクレーム・健康被害・法的な話は、AIが決めるべきことではありません。
  その場合は返信案と一緒に **「⚠ オーナー判断が必要です」** と表示されます。
  最終判断は必ずご自身で行ってください。
- 送信前に文章は一度目を通してください。空き時間などは【穴埋め】になっています。

## 困ったとき

- 返信が自分っぽくない → 「もっと絵文字多めで」「もっとあっさりで」とそのまま言えばOK。
  続けて「この設定で保存して」と言えば以後も反映されます。
- キャンセル料の話が出ない → 初期設定でキャンセルポリシーを登録してください。
  設定が無い場合、Salon Replyは勝手に請求文を作りません(安全のためです)。
- 長すぎる/短すぎる → 初期設定の「文章の長さ」を変えるか、その場で「短く」と言ってください。

その他は同梱の「FAQ」をご覧ください。

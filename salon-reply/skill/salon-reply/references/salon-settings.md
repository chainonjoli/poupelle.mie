# salon-settings — サロン設定の登録と使い方

Salon Replyの返信は、サロン設定があるほど「そのサロンらしく」なる。
ただし **設定ゼロでも動く** ことが大前提。未入力を理由に返信を止めない。

## 設定の優先順位

1. 会話の中でユーザーが伝えた内容・その場の修正指示(最優先)
2. `my-salon.md`(作業フォルダ、またはスキルフォルダ内)
3. デフォルト設定

会話内の指示と `my-salon.md` が食い違ったら会話内を優先し、
「my-salon.md も更新しておきますか?」と一言だけ添える(ファイルに書ける環境の場合)。

## デフォルト設定(未設定時)

- 文体: 丁寧・親しみやすい。過剰敬語なし
- 絵文字: 0〜1個
- 営業感: 押し売りしない。次回予約は自然な場面のみ
- キャンセルポリシー: **無し扱い**。キャンセル料に言及しない
- 遅刻ルール: 無し扱い。「できる範囲で調整」の姿勢
- 営業時間・定休日・予約方法・料金: 不明。必要な箇所は穴埋めにする

## 初期設定インタビュー

ユーザーが「初期設定」「設定したい」「最初の設定」などと言ったら、
次の質問を **1回のメッセージにまとめて** 提示する(小出しに何往復もしない)。
全部で3分で終わること、飛ばしてよいことを最初に伝える。

> Salon Replyの初期設定をしますね。答えられるところだけでOKです(あとからいつでも変更できます)。
>
> 1. サロン名(お客様への文面に出す名前)
> 2. 業種(エステ / ネイル / まつ毛 / リラクゼーション / その他)
> 3. 主な客層(例: 30〜40代女性、リピーター中心)
> 4. ふだんの文章の雰囲気(丁寧め / フレンドリー / その中間)
> 5. 絵文字(使わない / 1通に1個くらい / 多め)
> 6. 文章の長さ(短め / ふつう / しっかりめ)
> 7. 営業感(売り込みは一切しない / 自然な範囲ならOK)
> 8. キャンセルポリシー(例: 当日50%。無ければ「なし」)
> 9. 遅刻のときのルール(例: 15分以上は施術短縮。無ければ「なし」)
> 10. 予約方法(LINE / ホットペッパー / 電話 など)
> 11. 営業時間と定休日
> 12. 初回のお客様に必ず伝えたいこと(場所の目印・駐車場・持ち物など)
> 13. その他、接客で大切にしていること

回答を受け取ったら、下のテンプレート形式に整理して見せ、
ファイルに書ける環境なら `my-salon.md` として保存する。
書けない環境(チャットのみ)なら、
「このブロックをコピーして保存し、次回から会話の最初に貼ってください。
 プロジェクト機能があれば、プロジェクトの指示欄に貼っておくと毎回自動で反映されます」
と案内する。

## my-salon.md テンプレート

```markdown
# わたしのサロン設定(Salon Reply用)

- サロン名:
- 業種:
- 主な客層:
- 文章の雰囲気:
- 絵文字:
- 文章の長さ:
- 営業感:
- キャンセルポリシー:
- 遅刻のルール:
- 予約方法:
- 営業時間:
- 定休日:
- 初回のお客様への案内(場所・駐車場・持ち物など):
- 接客で大切にしていること:
```

## 設定の使い方の注意

- **設定に無いルールを作らない**。ポリシー未設定ならキャンセル料の話をしない。
  営業時間未設定なら時間を勝手に書かず穴埋めにする。
- 設定の「接客で大切にしていること」は文面の細部に反映する
  (例:「急かさない接客」→ 次回予約の誘い方を特にソフトに)。
- 設定変更はいつでも受け付ける。「もう少し砕けた感じで」と言われたら、
  その場で直しつつ、設定自体の更新も提案する。

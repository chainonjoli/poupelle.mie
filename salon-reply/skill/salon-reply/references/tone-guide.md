# tone-guide — 接客文章の作り方(全シーン共通)

Salon Replyの文章は「上手な文章」ではなく「その人が書いたように見える、感じのいい返信」を目指す。
お客様は文章のうまさではなく、「ちゃんと読んでくれた」「大事にされている」と感じるかで判断する。

## 基本構造

ほとんどの返信はこの3つの順番で組み立てる。

1. **相手の言葉への反応** — 最初の一文は、相手が書いたこと・相手の感情に応える。
   挨拶やお礼の定型文から入らない。
2. **必要な情報・対応** — この状況で伝えるべきことを、必要な分だけ。
3. **次の行動** — 読んだお客様が「次に何をすればいいか」が分かる形で締める。

必要に応じて最後に **気遣いの一言** を足す(体調・天気・楽しみにしている気持ちなど)。
ただし毎回同じ気遣いフレーズを貼ると一気にテンプレ臭くなるので、状況に合うときだけ。

## 長さ

- 基本: LINEの1画面に収まる。2〜6文。
- 初回来店前の案内など情報が多いもの: 少し長くて可。ただし改行と空行で読みやすく。
- 直前の連絡(遅刻・直前キャンセル)への返信: 短く、要点を先に。相手は今バタバタしている。
- 長文のお便りをもらったとき: 相手の長さに全部付き合わない。要点を拾って感じよく返す。

## 敬語レベル

サロン設定の「丁寧さ」に従う。設定が無いときのデフォルトは
**「丁寧だけど、かしこまりすぎない」**。ホテルではなく、行きつけの個人サロンの距離感。

| 過剰(避ける) | ちょうどいい |
|---|---|
| 承知いたしました。 | かしこまりました / わかりました、大丈夫ですよ |
| ご来店いただけますと幸いでございます | お待ちしていますね |
| 〜させていただいております(連発) | 〜しています / 〜していますね |
| ご不明な点がございましたらお気軽にお問い合わせくださいませ | 気になることがあれば、いつでも聞いてくださいね |
| この度は誠に申し訳ございませんでした(軽い場面で) | ごめんなさい / 申し訳ありません |

謝罪の重さは場面に合わせる。軽い日程変更に「誠に申し訳ございません」は重すぎ、
クレームに「ごめんなさい💦」は軽すぎる。

## 絵文字

サロン設定に従う。設定が無ければ **1通に0〜1個**。

- 使うなら文末に自然に(😊 🌸 ✨ など柔らかいもの)
- キャンセル料の請求・クレーム対応・体調の相談には原則使わない
- お客様が絵文字たっぷりなら、少し寄せてよい(ただし同じ量まで真似しない)

## 相手のテンションに合わせる

- **ぶっきらぼうな相手**(「明日空いてる?」): こちらは普通に丁寧に。ただし短めに返す。
  長文で返すと温度差が出る。
- **絵文字・ノリが明るい相手**: 少し明るく。絵文字1〜2個まで寄せてよい。
- **怒っている相手**: 絵文字なし。短い文。感情に乗らず、落ち着いた丁寧さで。
- **深夜に届いた連絡**: 返信文の冒頭は「おはようございます」で朝送る前提の文と、
  「夜分にすみません、確認しました」ですぐ送る文のどちらが自然かを状況で選ぶ。
  迷ったら朝送る前提で作り、状況メモに「朝の送信を想定」と書く。

## AIっぽさチェック(送信前に自分で確認する)

次のどれかに当てはまったら書き直す。

- [ ] 「ご連絡ありがとうございます。」「承知いたしました。」だけで実質的な中身がない
- [ ] どのサロンのどのお客様にも送れてしまう(=その状況に応えていない)
- [ ] 「〜でございます」「〜くださいませ」が2回以上ある
- [ ] 同じ語尾(〜です。〜です。〜です。)が3連続している
- [ ] 箇条書き・記号・見出しだらけでビジネスメールみたいになっている
  (案内で箇条書きを使うのは可。ただしLINEの会話として自然な範囲で)
- [ ] 聞かれていない営業(次回予約・別メニュー・物販)が入っている
- [ ] 相手の名前の呼びかけが不自然に多い
- [ ] 「!」が3個以上ある

## 「テンプレ終わり」の禁止

悪い例(状況: 子どもの発熱で当日キャンセル):

> ご連絡ありがとうございます。承知いたしました。またのご予約をお待ちしております。

これは返信ではなく受領確認。この状況で本当に必要なのは、
(1) お子さんへの気遣い (2) キャンセル扱いの明確化(料金はどうなるか) (3) 再予約の入り口。
必要な情報・感情・次の行動がそろって、はじめて返信になる。

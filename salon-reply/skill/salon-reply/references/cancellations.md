# cancellations — キャンセル・遅刻の対応判断

キャンセル対応は Salon Reply の一番の腕の見せどころ。
「感じよく受ける」と「サロンを守る」を両立させる。

## 共通の考え方

- **連絡をくれたこと自体はプラス**。無断より何倍もいい。責めるトーンは連絡する気を失わせ、
  次から無断キャンセルに変わる。
- ただし「いつでも無料でドタキャンできるサロン」になってもいけない。
  ポリシーが設定されているなら、感じよく・淡々と適用するのが基本。
- キャンセル料の話は **設定にポリシーがある場合だけ**。無いのに持ち出すのは禁止。
- 損失への感情(「困ります」「材料を用意していたのに」)は文面に出さない。

## 判断マトリクス

返信を作る前に3つを見る: **タイミング × 事情 × 関係性**

### タイミング別の基本方針

| タイミング | 方針 |
|---|---|
| 前日まで | 快く受ける。ポリシー対象外が普通。再予約の入り口を一言添える |
| 当日 | ポリシーがあれば原則適用。ただし下の「迷ってよいケース」参照 |
| 直前(開始1時間以内) | ポリシーがあれば明確に伝える必要度が高い。文面は短く淡々と |
| 無断(来なかった) | 下の専用セクションに従う |

### 当日・直前で「請求する/しない」に迷ってよいケース → 2案出す

以下が重なるときは、オーナーの判断が分かれるのが健全。
**「請求する案」と「今回は免除する案」の2案** を出し、判断材料を状況メモに書く。

- やむを得ない事情(子どもの発熱・本人の体調不良・身内の不幸・事故)
- 長く通ってくれている常連で、初めての当日キャンセル

逆に、事情の説明が無い自己都合・繰り返しの当日キャンセルは、
ポリシーどおり伝える1案でよい(伝え方はやわらかく)。

### キャンセル料を伝える文の型

1. 受け止め(「ご連絡ありがとうございます」「それは大変でしたね」)
2. キャンセル自体の了承
3. ルールの引用(「恐れ入りますが、当サロンでは当日のご変更は◯◯を頂いております」)
   — 「規定ですので」と突き放さず、事前にお伝えしているルールとして淡々と
4. 支払い方法(次回来店時 / 振込 など。設定に無ければ「お支払い方法はご相談させてください」)
5. 関係維持の一言(「また落ち着いたらぜひいらしてくださいね」)

免除する場合も **「本来は当日◯◯を頂いていますが、今回は結構ですよ」** と
ルールの存在は伝える。黙って免除するとポリシーが無いのと同じになる。

## 無断キャンセル(来なかった)

感情的にならない。順番は **事実 → 気遣い → ルール → 今後**。

- **当日中に送る場合**: まだ事故や急病の可能性がある。責める前に安否・状況確認のトーンで。
  > 本日◯時にご予約いただいていましたが、ご来店が確認できずご連絡しました。
  > 何かあったのではと心配しています。ご都合が悪くなった場合は、
  > 短いメッセージで大丈夫なので教えていただけると助かります。
- **後日・理由が分かってから**: 事務的に整理する。
  ポリシーがあれば適用を伝える。無ければ、今後の予約について仕組みで対応
  (「前日にこちらから確認のご連絡を入れますね」)。
- 繰り返す相手でも、文面で罰しない。**仕組みで守る**:
  前日確認の導入、(オーナー判断事項として)事前決済や予約方法の変更の検討を
  状況メモで提案する。文面には出さない。

## 日程変更として来たキャンセル

「キャンセルではなく変更したい」は歓迎して受ける(`reservations.md` 参照)。
当日変更でポリシー対象になり得る場合も、**まず新しい日程を決める姿勢** を先に。
ルールに触れる必要があるなら、日程の話のあとに短く。

## G. 遅刻

見るもの: **何分遅れるか / 後ろに次の予約があるか(設定・会話から) / 謝っているか**

- 数分〜10分程度: 安心させるのが最優先。
  > ご連絡ありがとうございます。大丈夫ですよ、気をつけていらしてくださいね。
- それ以上で、施術時間に影響が出そう: 責めずに、影響だけ事実として先に伝える。
  遅刻ルールが設定にあればそれを使う。無ければ:
  > お気をつけてお越しください。到着のお時間によっては、
  > 後のご予約の関係で施術内容を少し調整させていただくかもしれません。
  > できる限りフルでご案内できるようにしますね。
- 大幅遅刻で施術自体が難しい可能性: 選択肢を提示(短縮メニュー or 日程変更)。
  この判断は空き状況次第なのでオーナー確認が要る旨を状況メモに書く。
- 急かす文言(「早くお願いします」)、圧(「次の方がいますので」)は使わない。
  事実の共有と気遣いだけで十分伝わる。

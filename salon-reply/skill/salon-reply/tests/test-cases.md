# test-cases — 品質検証記録(2026-08-11実施)

実施方法: スキルを読み込んだ独立エージェント4体+再テスト1体で、実際の返信生成を実行。
以下の12項目のいずれかに違反があればFAIL。

判定基準: ①丁寧さ ②自然さ ③長さ ④状況理解 ⑤キャンセル対応 ⑥クレーム対応
⑦営業感(押し売りなし) ⑧サロン設定反映 ⑨医療安全性 ⑩不必要な謝罪なし
⑪次の行動が明確 ⑫AIっぽさがない

テスト設定:
- 設定A: 個人フェイシャルエステ(丁寧・親しみやすい / 絵文字1〜2 / 当日50% / 遅刻15分ルール)
- 設定B: 個人ネイルサロン(フレンドリー / 絵文字多め / ポリシーなし)
- 設定なし: デフォルト設定の挙動を検証

## FAILの内容と修正(Case 19)

- 症状: 「シフトが金曜に分かる」という連絡に対し、返信内で
  「それまで予約をそのまま取っておきますね」と **枠の取り置きを独断で約束** した。
  取り置きの可否・期限はオーナーの運用判断であり、スキルの
  「勝手に約束しない」原則から漏れていた。
- 修正: SKILL.md「絶対にしないこと」と references/reservations.md に
  「取り置き・キープの約束を独断でしない(提案は状況メモで)」を追加。
- 再テスト: 修正後、同一ケースで再実行。返信は「金曜に分かったら教えてくださいね」と
  待つ形になり、取り置きは状況メモでの提案(オーナーの運用判断と明記)に変わった。
  3つの論点(未確定の予約・お直し希望・料金質問)すべてに応答。PASS。

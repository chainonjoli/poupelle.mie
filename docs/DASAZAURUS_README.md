# ダサザウルス ～まだ見ぬステージへ～

バンドザウルスに憧れる、まだ無名の恐竜バンド「ダサザウルス」と遊ぶ **しゃべる神経衰弱** です。

このゲームの目的は、神経衰弱に勝つことではありません。
**「この恐竜たち、なんか応援したくなるな」** と思ってもらうことです。

## あそびかた（5秒でわかる）

1. カードを2枚めくる
2. おなじ絵なら せいかい！ ちがったら閉じる
3. ぜんぶそろえたら **ライブ開始！！**

カードをめくるたびに、メンバーが応援したり、ツッコんだり、寝たりします。

## 遊ぶ

ブラウザで `dasazaurus.html` を開くだけ。ビルド不要・外部画像不要（キャラクターはすべてSVG、効果音とBGMはWebAudio合成）。

ローカルで動かす場合:

```bash
python3 -m http.server 8000
# → http://localhost:8000/dasazaurus.html
```

スマホ縦画面・片手操作を前提にデザインしています。

## ステージ

クリアするたびにライブ会場がステップアップします。

**公園 → レストラン → 山 → ライブハウス → 幕張メッセ**

全カードをそろえるとライブが始まります。観客は少ないけれど、みんな最高の笑顔。
そして最後に、スマホに1通の通知が届きます。

> あなたのライブを見ました。 — 差出人：？？？

## ファイル構成

```
dasazaurus.html               … 画面（1ページ）
styles/dasazaurus.css         … スタイル
scripts/dasazaurus/
  cards.js                    … カード・難易度・ステージ定義（純データ）
  lines.js                    … 台詞データ 150種以上（純データ）
  engine.js                   … 神経衰弱ロジック＋リアクション抽選（DOM非依存）
  characters.js               … キャラクターSVGアート
  audio.js                    … WebAudio合成のSE/BGM
  app.js                      … 画面遷移・盤面UI・演出
tests/dasazaurus-test.js      … 単体テスト
docs/DASAZAURUS_SPEC.md       … 仕様書
```

## テスト

```bash
node tests/dasazaurus-test.js
```

デッキ生成・状態遷移・隠しキャラ・台詞数（100種以上）・リアクション抽選（重複回避／掛け合い／居眠り）を検証します。

## 記録について

進行状況（ステージ・ベスト記録・DOKIDOKIとの遭遇）は、ブラウザの `localStorage` にのみ保存されます。サーバーには何も送信しません。「せってい → きろくを けす」でいつでも消せます。

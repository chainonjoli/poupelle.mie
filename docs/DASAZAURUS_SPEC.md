# ダサザウルス ～まだ見ぬステージへ～ 仕様書

## 1. コンセプト

- ジャンル: しゃべる神経衰弱（メモリーマッチ）
- 最優先の目的: **ダサザウルスというIPを好きになってもらうこと**。勝敗は二の次。
- 体験の柱: 「笑える」「少し泣ける」「応援したくなる」
- 世界観: キラキラ輝くバンドザウルスに憧れる、まだ実力も知名度もない恐竜バンド。
  いつか見つけてもらえる日を夢見て、仲間と笑いながら頑張っている。
- 対象: 子どもでも遊べる。スマホ縦画面・片手操作。

## 2. キャラクター仕様

キャラクターはすべて `scripts/dasazaurus/characters.js` のSVGで描画（外部画像なし）。
公式ビジュアル（恐竜マスクをかぶった普段着のバンド）を基準にデザイン。
顔・色・体格・衣装は全画面（タイトル/ホーム/カード/吹き出し/ライブ）で共通のSVGを使い、変化しない。

| ID | 名前 | 見た目 | 性格・挙動 |
| --- | --- | --- | --- |
| takeru | タケル憧れ | 赤ティラノマスク・白T（ピンクで「タケル憧れ」）・黒短パン・赤ソックス | 前向き。何でもポジティブ。すぐ夢を語る |
| funky | ファンキー無糖 | 青ティラノマスク・白T（「無糖」）・青パンツ・無糖ブラック缶 | 冷静。ツッコミ担当。少し心配性 |
| terako | 大騒テラコ | 橙トリケラトプスマスク・オレンジのつなぎ・両手を上げた大騒ぎポーズ | 応援団長。声が大きい。成功すると大騒ぎ |
| shibakuzo | SHIBAKUZO | 緑ティラノマスク（半目）・白T（「しばくぞ」）・マスタードパンツ・サンダル・zzz | いつも眠そう。一定確率で寝る。睡眠優先 |

## 3. ルール

1. カードを2枚めくる。同じ絵なら成功（開いたまま）。違えば約0.9秒後に閉じる。
2. 全ペアをそろえるとクリア → ライブ演出へ。
3. 時間制限・ペナルティなし（子どもが安心して遊べる）。

### デッキ生成（engine.js `buildDeck`）

- メンバー4種（タケル/ファンキー/テラコ/SHIBAKUZO）は必ずデッキに入る。
- 残りペアはアイテムカード28種からランダム抽出。
- **隠しキャラ**: 確率 7%（LEGENDは15%）でアイテム1種が DOKIDOKI ペアに差し替わる。
- カードはFisher–Yatesでシャッフル。乱数はmulberry32（seed指定でテスト可能）。

### カード（世界観の表現）

メンバー4種＋DOKIDOKI＋アイテム28種:
ギター・ドラム・キーボード・マイク・バンドタオル・ライブチケット・ペンライト・スピーカー・おんぷ・ヘッドホン・ラジカセ・メガホン・ピザ・ビール・おにく・やさい・おにぎり・ラーメン・カレー・かさ・やま・ほしぞら・こうえん・きざい車・ゆめノート・恐竜マスク・はな・スニーカー

## 4. 台詞システム（このゲーム最大の特徴）

- 総台詞数 **153種**（`lines.js`、テストで100種以上を保証）。
- 場面: `start` / `first`（1枚目）/ `match` / `miss` / `combo`（2連続以上）/ `sleep` / `clear` / `doki`
- 抽選は `engine.js ReactionPicker`:
  - 直近14件に出た台詞は再抽選して**重複感をなくす**
  - 16%で2人の**掛け合い**（12組・1.5秒間隔で2連続表示）
  - SHIBAKUZOが選ばれたとき28%で場面を無視して**居眠り台詞**＋いびきSE
  - 同じキャラの連続発話を避けめに補正
- 1枚目めくりは50%の確率で発話（テンポ優先）。2枚目は毎回発話。

## 5. ステージ進行

クリアするたびに `stageIndex` が進む（localStorageに保存）。難易度とは独立。

| # | 会場 | 観客数 | クリア後のキャプション（少し泣ける担当） |
| --- | --- | --- | --- |
| 1 | 公園 | 3 | お客さんはハトと子どもだけ。でも、みんな最高の笑顔で演奏した。 |
| 2 | レストラン | 6 | 拍手よりフォークの音のほうが大きい。それでも、アンコールが1回きた。 |
| 3 | 山 | 9 | 星空がスポットライトの代わりだった。声は、どこまでも届いた。 |
| 4 | ライブハウス | 14 | 手売りのチケット、ぜんぶで14枚。ぜんいんの顔と名前を覚えている。 |
| 5 | 幕張メッセ | 24 | まだ見ぬステージのはずだった場所に、いま立っている。 |

背景はステージごとにグラデーション＋装飾（ゲーム中/ライブ中で別配色）で豪華になっていく。
幕張メッセ到達後はそのまま幕張でライブし続けられる。

## 6. クリア演出（時系列）

1. 全ペア成立 → クリア台詞 → 1.1秒後にライブ画面へ
2. スポットライト・紙吹雪60枚・ファンファーレ＋歓声（観客数でボリューム増）
3. メンバー4人が演奏アニメ（rock 0.42s交互）
4. 観客列（少ないけど笑顔の絵文字）。**列の最後にチャーミーのシルエット**が3秒かけてじわっと現れる（演出のみ・名前は出さない）
5. 3.6秒後: スマホ通知風バナー「**あなたのライブを見ました。**」差出人: **？？？**（最後まで明かさない）
6. 5.6秒後: リザルトカード（て数/タイム/最大コンボ）＋次ステージへ

## 7. 隠しキャラ演出

- DOKIDOKIペアをそろえると: 専用SE（キラキラ＋鼓動）＋全画面カットイン2.2秒＋専用台詞
- 一度でも遭遇すると `dokiSeen` が保存され、メンバー画面の「？？？」が DOKIDOKI として解放される。

## 8. UI / 演出

- スマホ縦画面（max-width 480px・100dvh・safe-area対応）、全操作が画面下半分中心で片手完結。
- カードは3D flip（rotateY 0.3s）、マッチでポップ（scale 1.14）＋金色ハイライト。
- コンボ表示（2連続以上）、吹き出しはキャラSVG＋名前＋台詞でホップアニメ。
- SE/BGMはWebAudio合成（外部ファイルなし）: めくり/正解（コンボで音程UP）/はずれ（コミカル）/いびき/キラキラ/ファンファーレ/歓声/通知音。設定で個別ON/OFF。
- フォント: Mochiy Pop One＋M PLUS 1p（Google Fonts、読み込めない環境ではsans-serifにフォールバック）。

## 9. データ保存

`localStorage` キー `dasazaurus-save-v1`:

```json
{
  "stageIndex": 0,
  "totalClears": 0,
  "best": { "easy": { "moves": 9, "timeMs": 9000 } },
  "dokiSeen": false,
  "sfx": true,
  "bgm": true
}
```

外部送信なし。プライベートブラウズ等で保存できない場合も記録なしで遊べる。

## 10. アーキテクチャ

- `cards.js` / `lines.js`: 純データ（CommonJS/ブラウザ両対応）
- `engine.js`: DOM非依存の純ロジック（デッキ生成・状態遷移・台詞抽選）→ Nodeで単体テスト
- `characters.js`: SVG生成関数（`charSVG(id, opt)`）
- `audio.js`: WebAudio（ユーザー操作で `unlock()`、モバイル自動再生制限対応）
- `app.js`: 画面遷移・盤面・演出のみ。ロジックはengineに委譲

### 状態遷移（MemoryGame.flip）

```
flip(i) → 'reject'  … クリア済み/ミス解決待ち/同一カード/マッチ済み
        → 'first'   … 1枚目
        → 'match'   … 一致 { combo, cleared, isDoki }
        → 'miss'    … 不一致 → UIが0.9秒後に closeMiss()
```

## 11. テスト（tests/dasazaurus-test.js）

`node tests/dasazaurus-test.js` — 54項目:

- データ整合性（ID重複なし・台詞100種以上・難易度4・ステージ5）
- 全難易度のデッキ生成（枚数・ペア・メンバー必入・隠しキャラ差し替え）
- 状態遷移（first/match/miss/reject/closeMiss/クリア/コンボ）
- 隠しキャラの `isDoki` フラグ
- リアクション抽選（形式・連続重複なし・多様性・掛け合い・居眠りの発生）

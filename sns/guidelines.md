# 運用ガイドライン

全アカウント・全担当（AIエージェント含む）共通のルールです。2アカウントはトーンが異なるため、まず「どちらのアカウントの原稿か」を確認してから該当セクションに従ってください。

## トーン＆マナー

### 共通
- ネガティブな話題（批判・他作品/他店との比較・政治・時事論争）には触れない
- 絵文字は1投稿に0〜3個。飾りではなく意味のある場所に使う

### @ise.poupelle.likes（プペルファンアカウント）
- 基本は **「星を見上げる、あたたかい語り口」**。作品世界の「信じ抜くこと」「見上げること」を大切にする
- 読者には子ども・保護者が含まれる。誰が読んでも安心できる言葉を使う

### @chainonjoli（エステサロンアカウント）
- 基本は **清潔感・信頼感・癒し**。落ち着いた丁寧な語り口で、押し売り感を出さない
- 効果の断定表現（「必ず痩せる」「シミが消える」等）は使わない。景品表示法・医療広告規制に抵触するリスクがあるため、「〜を目指す」「個人の感想」等の表現にとどめる
- 予約導線（プロフィールのリンク・DM）を投稿の最後にさりげなく置く

## プラットフォーム別の書き分け

| | Instagram | Threads |
|---|---|---|
| 起点 | ビジュアル（写真・イラスト） | テキスト（会話・問いかけ） |
| 文体 | 整った「お知らせ」寄り | 話しかける口語 |
| 長さ | キャプション〜400字目安 | 500字以内・1投稿1トピック |
| ハッシュタグ | 本文末に5〜10個 | 0〜1個 |
| 頻度目安 | 週1〜2投稿＋ストーリーズ随時 | 週2〜3投稿 |

頻度は「守れる最低ライン」で設定している。増やすより **止めない** ことを優先する。

## 権利・表記の注意（最重要・主に @ise.poupelle.likes）

- 『えんとつ町のプペル』は **西野亮廣氏・CHIMNEY TOWN の作品**。本プロジェクトはファン活動であり、全アカウントのプロフィールと投稿で公式と誤認される表現をしない
  - NG例: 「公式」「オフィシャル」の語、公式ロゴの無断使用
  - OK例: 「ファンによる非公式プロジェクトです」の明記
- 映画本編の映像・音源・公式イラストを無断転載しない。使ってよいのはこのリポジトリ内の自作素材と、自分たちで撮影した写真のみ
- イベント写真に写る **子どもの顔・氏名** は、保護者の同意なく投稿しない。後ろ姿・手元・ぼかしを基本にする

## 禁止事項

- 自動化ツールによる自動投稿・自動フォロー・自動いいね（Meta規約違反のリスク）
- フォロワー購入、相互フォロー企画などの水増し行為
- 同一文面の複数アカウント同時投稿（スパム判定リスク）
- ise でのDMによる個人情報のやりとり（イベント申込等は必ずサイトのフォームへ誘導）。chainon の予約DM対応は本業の通常業務としてOK
- ise と chainon の話題の混在（プペルの話題は ise へ。詳細は `accounts.md`）

## 炎上・トラブル時の初動

1. **止める**: 予約済み投稿を含め、いったん全投稿を停止
2. **消さない**: 指摘を受けた投稿は独断で削除せず、スクリーンショットで記録してからチーム（人間）で判断
3. **一人で返信しない**: 謝罪・反論はチームで文面を決めてから

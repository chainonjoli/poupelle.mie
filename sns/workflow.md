# 週次運用フロー

「企画 → 執筆 → 校閲 → 投稿 → 分析」を1週間サイクルで回します。各ステップの担当エージェントに Claude Code から依頼してください。

## 週のサイクル

| 曜日 | やること | 担当 |
|---|---|---|
| 月 | 今週の投稿予定をカレンダーで確認・調整 | `sns-planner` |
| 火 | 今週分の原稿をまとめて執筆（`sns/drafts/` へ） | `sns-writer` |
| 水 | 全ドラフトの公開前チェック | `sns-reviewer` |
| 木〜日 | カレンダーに沿って **人間が** 投稿 | 人間 |
| 随時 | コメント・リプライへの返信（24時間以内目安） | 人間 |

## 月のサイクル

| タイミング | やること | 担当 |
|---|---|---|
| 月末 | インサイト数値を転記 → 月次レポート作成 | 人間 → `sns-analyst` |
| 月初 | レポートを踏まえて翌月のカレンダー作成 | `sns-planner` |

## 依頼の例

```
# 月曜（企画）
「sns-plannerで、今週のカレンダーを確認して足りない投稿を提案して」

# 火曜（執筆）
「sns-writerで、カレンダーの今週分の原稿を全部書いて」

# 水曜（校閲）
「sns-reviewerで、sns/drafts/ の今週分を全部レビューして」

# 月末（分析）
「sns-analystで、この数値から7月のレポートを作って:（インサイト数値を貼り付け）」
```

## ファイルの流れ

```
sns/calendar/2026-07.md     ← planner が作る「いつ・どこで・何を」
        ↓
sns/drafts/2026-07-10_shrine_ig.md   ← writer が書く原稿
        ↓ reviewer の ✅ が出たら
（人間がアプリから投稿）
        ↓
sns/reports/2026-07.md      ← analyst がまとめる振り返り
```

## ドラフトのファイル名規則

`YYYY-MM-DD_アカウント_プラットフォーム.md`

- アカウント: `main`（メイン） / `shrine`（推し色神社） / `adventure`（探検団）
- プラットフォーム: `ig`（Instagram） / `th`（Threads）
- 例: `2026-07-10_shrine_ig.md`

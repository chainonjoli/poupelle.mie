# アカウント設計

実在する2つのInstagramアカウントを軸にした、2アカウント × 2プラットフォーム（Instagram / Threads）の体制です。ThreadsアカウントはInstagramアカウントに紐づくため、既存のアカウントでそのままThreadsも開始できます。

2つのアカウントは目的がまったく異なります。**ise はプペルのファン活動、chainon は本業のエステサロン集客**。混ぜないことが最重要ルールです。

## アカウント一覧

### 1. [@ise.poupelle.likes](https://www.instagram.com/ise.poupelle.likes/) — 『えんとつ町のプペル』ファンアカウント

- **目的**: プペルへの愛の発信と、プロジェクト（上映会・推し色神社・えんとつ町探検団）への参加者づくり
- **想定フォロワー**: プペルファン、上映会に参加した家族、伊勢・明和など三重の子育て層
- **Instagram**: イベント写真、活動レポートのカルーセル、神社・探検団のビジュアル投稿
- **Threads**: 運営の裏話、参加者への感謝、「推し色」の問いかけなど会話系
- **現在のフェーズ**: 2026年5月30日の上映会は開催済み。御礼と思い出の発信、神社・探検団への送客、次回開催への期待づくりが中心
- **注意**: ファン活動のため、プロフィールに非公式である旨を明記する

### 2. [@chainonjoli](https://www.instagram.com/chainonjoli/) — エステサロンアカウント（本業）

- **目的**: サロンの集客・予約につなげる。既存のお客様との関係維持と、新規のお客様への信頼づくり
- **想定フォロワー**: 既存・見込みのお客様、地域の美容関心層
- **Instagram**: 施術メニュー・ビフォーアフター（同意のあるもののみ）、サロンの雰囲気、キャンペーン、お客様の声、セルフケアのヒント
- **Threads**: オーナーの人柄が伝わる日常、美容・セルフケアの豆知識、お客様との何気ない会話
- **トーン**: 清潔感・信頼感・癒し。ファンアカウントのにぎやかさとは切り分ける

## 2アカウントの使い分けの原則

| | @ise.poupelle.likes | @chainonjoli |
|---|---|---|
| 目的 | ファン活動・イベント参加者づくり | サロンの集客・予約 |
| 主語 | プロジェクト・作品への愛 | サロン・オーナー |
| 話題 | 上映会、神社、探検団、プペル | 施術、美容、サロンの日常 |
| 読者 | ファン・親子 | お客様・美容関心層 |

- **プペルの話題は原則 ise に投稿する。** chainon にプペル投稿が続くと、お客様のフィードの期待とずれてフォロー解除につながる
- 例外として、chainon で「オーナーの地域活動」として上映会などに **たまに** 触れるのはOK（人柄が伝わり本業の信頼にもつながる）。目安は月1回まで、あくまでサロンの読者向けの書き方で
- 相互送客は控えめに: chainon のプロフィールに ise へのリンクを置く程度にとどめ、投稿での相互宣伝は乱発しない
- 同一文面の同時投稿はしない（スパム判定リスク）

## 推し色神社・探検団の専用アカウントについて

当面は **作らず**、@ise.poupelle.likes 内のシリーズ投稿として運用します。分離を検討するのは次の条件が揃ってから:

- 神社/探検団系の投稿が安定して他の投稿よりエンゲージメントが高い
- 週2本以上をそのテーマだけで継続できる体制がある

## 運用上の注意（複数アカウント）

- 投稿前に **どちらのアカウントに出すのか** を必ず確認する（誤爆がいちばんの事故。本業アカウントへのファン投稿誤爆は特に注意）
- Metaの規約上、なりすまし・水増し目的の複数アカウントは禁止。ここでの複数運用は「ファン活動と本業の分離」であり正当な使い分け
- ログイン管理は Instagramアプリのアカウント切替機能でまとめ、二段階認証を必ず有効にする
- サロンのお客様の写真・ビフォーアフターは、必ず本人の同意を得てから投稿する

## Threads立ち上げ手順

1. 各Instagramアカウントでログインした状態でThreadsアプリを開き、同じユーザー名でプロフィールを作成（数分で完了）
2. 最初の投稿は「はじめまして」＋活動紹介（テンプレは `templates/threads.md` 参照）
3. まず ise 側から開始し、運用が回ってから chainon 側も始める（Threadsの会話的な空気はサロンの人柄発信とも相性が良い）

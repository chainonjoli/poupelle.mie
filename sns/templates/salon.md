# サロン投稿テンプレート集（@chainonjoli 用）

エステサロン（本業）アカウントの型です。トーンは「清潔感・信頼感・癒し」。効果の断定表現は使わない（`guidelines.md` 参照）。

## Instagram

### 1. メニュー・施術紹介

```
【メニュー名】のご紹介です。

【どんな悩みの方に向いているか、1〜2行】
【施術の流れ・所要時間を簡潔に】

【お客様の声や、施術で大切にしていることを1〜2行】

ご予約・ご相談はプロフィールのリンクからどうぞ。

【地域×サロン系ハッシュタグ 5〜8個】
```
画像指示: 施術風景 or 施術スペースの写真。清潔感を最優先

### 2. サロンの日常・オーナーの人柄

```
【今日のサロンでの小さな出来事、季節の話題など2〜3行】

【お客様への気持ち・仕事への想いを1行】
```
画像指示: 店内・お花・ウェルカムドリンクなど、雰囲気が伝わる1枚

### 3. キャンペーン・お知らせ

```
【キャンペーン内容を1行で】

▼ 内容
【メニュー・料金・期間】

▼ ご予約
プロフィールのリンク、またはDMからお気軽にどうぞ。

【ハッシュタグ】
```

### 4. 地域活動の報告（月1回まで）

```
【サロンの外での活動を、お客様向けの言葉で2〜3行】
（例: 地域のこども向け上映会を開催しました、など）

【なぜやっているのか、サロンの想いとつなげて1〜2行】
```
※プペル色は薄めに。詳細はファンアカウント（@ise.poupelle.likes）に任せ、こちらでは「オーナーの人柄」として伝える

## Threads

### 1. 美容・セルフケアの豆知識

```
【季節や悩みに合わせたセルフケアのヒントを1つ、話しかける口調で】

【サロンでの実感・補足を1〜2行】
```

### 2. オーナーの日常

```
【仕事の合間の一コマを、友だちに話すように2〜3行】
```

## 共通ルール

- ビフォーアフター・お客様の写真は本人の同意を得たもののみ
- 「必ず」「絶対」「〜が治る」等の断定・医療的表現はNG
- 予約の押し付けはしない。導線は最後にさりげなく1回だけ

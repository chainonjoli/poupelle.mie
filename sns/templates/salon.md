# サロン投稿テンプレート集（@chainonjoli 用）

エステサロン（本業）アカウントの型です。トーンは「清潔感・信頼感・癒し」。効果の断定表現は使わない（`guidelines.md` 参照）。

**戦略: フィードで信頼を貯めて、ストーリーズで予約に変える。**
フィードは「お肌のためになる知識」でみんなの役に立つ場所、集客（空き状況・キャンペーン・予約導線）はストーリーズが担当します。

## Instagramフィード

### 1. お肌のためになる知識投稿（フィードの主力・週1〜2本）

カルーセル（複数枚画像）推奨。「保存してあとで見返したくなる」ことがゴール。売り込みは入れない。

```
1枚目（表紙）: 【悩みのフック】
 例:「夏の毛穴、目立つのはなぜ？」「冷房乾燥、放っておくと…」

2〜5枚目: 【原因や仕組みをやさしく1枚1トピックで】
 例: 原因 → 今日からできるケア① → ケア② → やりがちなNG

最後の1枚: 【まとめ＋「保存してあとで見返してね」】

キャプション:
【表紙の悩みに共感する導入 2〜3行】
【カルーセルの要点を短く】
【サロンでの実感をひとこと（宣伝はしない）】
保存しておくと、あとで見返せます🔖

【ハッシュタグ 5〜8個（お悩み系タグ中心: #毛穴ケア #乾燥肌対策 など）】
```
画像指示: 文字が読みやすいシンプルなデザインで統一（毎回同じテンプレデザインにするとアカウントの世界観ができる）

### 2. サロンの日常・オーナーの人柄（フィード サブ）

```
【今日のサロンでの小さな出来事、季節の話題など2〜3行】

【お客様への気持ち・仕事への想いを1行】
```
画像指示: 店内・お花・ウェルカムドリンクなど、雰囲気が伝わる1枚

### 3. 地域活動の報告（月1回まで）

```
【サロンの外での活動を、お客様向けの言葉で2〜3行】

【なぜやっているのか、サロンの想いとつなげて1〜2行】
```
※プペル色は薄めに。詳細はファンアカウント（@ise.poupelle.likes）に任せる

## Instagramストーリーズ（集客の主戦場・週2〜3回）

24時間で消えるからこそ、フィードでは出さない「予約・宣伝」をここに集める。

- **今週の空き状況**: 「今週は 木・金 に空きがあります」＋予約リンクスタンプ。毎週決まった曜日に出すと見る習慣がつく
- **キャンペーン告知**: 期間・内容・予約リンク。カウントダウンスタンプで締切を見せる
- **知識投稿のシェア**: フィードの知識投稿を当日と翌日にシェア「詳しくは投稿で🔖」
- **質問スタンプ**: 「お肌のお悩み、匿名で聞かせてください」→ 回答をそのまま次の知識投稿のネタにする（ネタ切れ防止にもなる）
- **施術の裏側・準備風景**: タオルを温めている、お部屋を整えている等の1枚。人柄と清潔感が伝わる
- **お客様の声**: 感想をいただいたら（本人の同意を得て）シェア

ハイライト機能で「ご予約方法」「メニュー」「お客様の声」を固定しておくと、プロフィールに来た人がいつでも見られる。

## 共通ルール

- フィードの知識投稿に売り込み・料金・予約催促を入れない（信頼を貯める場所。導線はストーリーズとプロフィールに任せる）
- ビフォーアフター・お客様の写真は本人の同意を得たもののみ
- 「必ず」「絶対」「〜が治る」等の断定・医療的表現はNG（知識投稿でも「〜と言われています」「〜がおすすめです」の範囲で）
- 知識投稿は一般的なセルフケアの範囲にとどめ、医療的な診断・治療の話はしない

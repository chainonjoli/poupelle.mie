# Threads投稿テンプレート集

Threadsは「会話の場」。お知らせの転載ではなく、話しかける・問いかけるのが基本です。1投稿500字まで、1トピックだけ。

## 1. 問いかけ（いちばん使う型）

```
【読者が自分のことを話したくなる質問を1つ】

【自分たちの答え・エピソードを2〜3行で先に見せる】
```

例:
```
あなたの「推しの色」ってなんですか？

うちのチームで聞いたら、全員バラバラでした。
理由を聞くと、それぞれの推しへの愛が濃くて面白かった…
```

## 2. 裏話・運営の日常

```
【今日あった小さな出来事を、友だちに話すように】

【感じたこと1行】
```

例:
```
上映会で使ったペンライト、まだ事務所の棚で光ってます。

片付けようとするたびに、あの日の客席を思い出して手が止まる。
```

## 3. 連投スレッド（深い話をするとき）

- 1投稿目: 結論 or いちばん面白いところ（ここで読むか決まる）
- 2〜4投稿目: 経緯・詳細を1投稿1論点で
- 最後: 問いかけ or サイトへの誘導で締める

## 4. お知らせ（控えめに）

```
【お知らせを1行で】

【なぜやるのか・どんな気持ちかを2〜3行】

詳しくはプロフィールのリンクから🔗
```

## 共通ルール

- ハッシュタグは0〜1個（Threadsではタグの羅列が嫌われる）
- Instagramと同じ文面をコピペしない（必ず書き直す）
- 他の人のプペル関連・推し活関連の投稿には積極的にリプライして会話に参加する（宣伝はしない、ただ楽しく話す）
- リプライへの返信は24時間以内を目安に

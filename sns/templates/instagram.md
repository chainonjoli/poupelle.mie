# Instagram投稿テンプレート集

sns-writer が原稿を書くときの型です。1行目が勝負（フィードでは冒頭しか表示されない）。

## 1. イベント告知

```
【日付】に【イベント名】を開催します🎪

（1行あける）
▼ どんなイベント？
【2〜3行で内容。誰向けか・何が体験できるか】

▼ 開催概要
📅 日時：
📍 場所：
🎫 参加費：

▼ 申し込み
プロフィールのリンクからどうぞ。

【ハッシュタグ 5〜10個】
```
画像指示: 1枚目=告知ビジュアル、2枚目以降=会場・過去の様子

## 2. イベントレポート・御礼

```
【イベント名】、無事に終了しました。

【当日の様子を情景で2〜3行。数字（来場者数など）があれば1つ入れる】

【印象的だったエピソードを1つ】

ご参加いただいたみなさま、本当にありがとうございました。
【次につながる一言】

【ハッシュタグ】
```
画像指示: カルーセル5〜10枚。子どもの顔は写さない（後ろ姿・手元・会場全景）

## 3. 推し色神社の参拝誘導

```
今日の推し色は「【色名】」。

【その色にまつわる短い物語・意味づけを2〜3行、幻想的なトーンで】

あなたの推しの色で、参拝してみませんか？
⛩ 推し色神社はプロフィールのリンクから。

【ハッシュタグ】
```
画像指示: その色を基調にしたビジュアル1枚（サイトの配色に合わせる）

## 4. 探検団のクエスト紹介

```
きょうのミッション、なんと【クエスト数】問連戦です🔥

【クエストの中身をネタバレしない範囲で1〜2行】

【対象年齢の子ども】なら夢中になるはず。
親子でチャレンジしてみてください。

▼ 遊び方はプロフィールのリンクから

【ハッシュタグ】
```
画像指示: ミニキャラを使った告知画像

## 5. ストーリーズ（随時）

- 準備の裏側を1枚写真＋一言（作り込まない）
- カウントダウン機能：イベント前
- 質問スタンプ：「推しの色おしえて」「次はどんなイベントがいい？」
- フィード投稿のシェア：投稿当日と翌日の2回

## 共通ルール

- 冒頭に「お知らせです」等の前置きを書かない（1行目から本題）
- リンクは「プロフィールのリンクから」に統一（キャプション内URLは踏めない）
- 投稿前チェックは必ず sns-reviewer を通す
